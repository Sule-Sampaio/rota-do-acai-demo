# 💜 Rota do Açaí — Cardápio Digital

> Demonstração de um cardápio digital responsivo desenvolvida para a **Rota do Açaí**, em Jaguaquara/BA.

Este projeto apresenta uma proposta de cardápio online onde o cliente pode visualizar os produtos, personalizar seu açaí, adicionar itens à sacola e finalizar o pedido diretamente pelo WhatsApp da loja.

> ⚠️ **Projeto demonstrativo e não oficial.**  
> Os preços e alguns dados comerciais utilizados na demonstração não representam necessariamente os valores atuais do estabelecimento.

## 📱 Sobre o projeto

A proposta foi criar uma experiência simples para o cliente realizar seu pedido sem precisar instalar nenhum aplicativo.

O fluxo funciona assim:

**Escolher produto → Personalizar → Adicionar à sacola → Informar entrega/retirada → Finalizar pelo WhatsApp**

Ao finalizar, as informações do pedido são organizadas automaticamente e encaminhadas para o WhatsApp do estabelecimento.

## 🛒 Como funciona o pedido

O cliente escolhe um produto no cardápio e pode selecionar os complementos disponíveis.

Depois de adicionar os produtos à sacola, ele informa se deseja **entrega ou retirada**.

Na finalização, o sistema monta automaticamente uma mensagem com as informações do pedido e direciona o cliente para o WhatsApp da loja.

Isso permite que o estabelecimento continue recebendo os pedidos pelo WhatsApp, mas de maneira muito mais organizada.
